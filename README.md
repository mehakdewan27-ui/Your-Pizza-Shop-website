## 🍕 Pizza Shop Website

A responsive pizza shop website built using **HTML and CSS**. This project was created as a real-world web development practice project to improve my skills in webpage structure, styling, layouts, and responsive design.

## 🌐 Live Demo

[View Live Website](https://cozy-frangollo-b598c4.netlify.app/)

## 📌 About the Project

This is a modern and responsive pizza shop website featuring a hero section, pizza menu, special offer section, "Why Choose Us" section, and contact footer.

The main goal of this project was to practice creating a complete website from scratch using HTML and CSS while focusing on clean layouts and responsive design.

## ✨ Features

* 🍕 Attractive hero section with background image
* 🧭 Navigation bar with smooth section navigation
* 🛒 Order/Cart button
* 🍕 Pizza menu with product cards
* 🛍️ Add to Cart buttons
* 🎉 Weekend special offer section
* ⭐ Why Choose Us section
* 📞 Contact information

* 📱 Responsive design for desktop, tablet, and mobile

## 📱 Responsive Design

The website is designed to work across different screen sizes:

* **Desktop:** 3-column pizza cards
* **Tablet:** 2-column pizza cards
* **Mobile:** 1-column pizza cards

The layout, typography, spacing, hero section, header, and footer are adjusted using CSS media queries.
